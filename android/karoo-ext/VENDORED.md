# Vendored karoo-ext

This folder is an unmodified copy of `lib/src/main` from
[hammerheadnav/karoo-ext](https://github.com/hammerheadnav/karoo-ext) at commit
`f79f103cd0e1a9808db64474796b30d822cc0b17` (library version 1.1.9), licensed under the
Apache License 2.0 (see `LICENSE`). Only `build.gradle.kts` was written for this project.

Hammerhead publishes the library on GitHub Packages, which requires a personal access token
even to download it. Building it from source keeps this project buildable by anyone.
